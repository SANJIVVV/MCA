Tim Berners-Lee

Inventor of the World Wide Web

About Him

Tim Berners-Lee is a British computer scientist who invented the World Wide Web.

He proposed the Web in 1989 while working at CERN.

Education

Tim Berners-Lee studied Physics at The Queen's College, Oxford.

He graduated in 1976.

Inventions

World Wide Web

He proposed the World Wide Web in 1989 while working at CERN.

HTML

HTML stands for HyperText Markup Language. It is used to create web pages.

HTTP

HTTP stands for HyperText Transfer Protocol. It is used to transfer information on the Web.

URL

URL stands for Uniform Resource Locator. It is used as the address of a web resource.

Achievements

  • Invented the World Wide Web
  • Created HTML and HTTP
  • Created the first web browser
  • Created the first web server
  • Founded the World Wide Web Consortium
